# lore_a-ue-gas-rpg
A top-down RPG built in Unreal Engine 5 using the Gameplay Ability System (GAS), inspired by Stephen Ulibarri’s Unreal Engine courses. Course names and descriptions are detailed in the README/Acknowledgements section.

## Acknowledgments
This project was inspired by Stephen Ulibarri's Unreal Engine courses on Udemy. The foundational concepts for the Gameplay Ability System (GAS) were learned through his courses, which are listed below:

- **[Unreal Engine 5 Gameplay Ability System Top Down RPG](https://www.udemy.com/course/unreal-engine-5-gas-top-down-rpg/)**: A comprehensive course on creating a top-down RPG using Unreal Engine's GAS framework.
- **[Unreal Engine 5 C++ The Ultimate Game Developer Course](https://www.udemy.com/course/unreal-engine-5-the-ultimate-game-developer-course/)**: A course on creating a third-person action RPG using UE5 C++.
- **[Unreal Engine 5 C++ Multiplayer Shooter](https://www.udemy.com/course/unreal-engine-5-cpp-multiplayer-shooter/)**: A course on creating a fast-paced, competitive multiplayer shooter using UE5 C++.
